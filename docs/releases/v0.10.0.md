## 亮点速览

| 主题 | 一句话 |
|---|---|
| 新入口 | 左侧栏出现「MCP 管理」，与「插件」「自动化任务」同一套面板机制 |
| 旧入口 | 「设置 → 内置插件 → 插件：MCP 管理」保留一个版本，计划在 0.11.0 移除 |
| 内部逻辑 | 配置读写、`/api/project-mcp/*` 路由、文件格式全部不变 |
| 兼容 | 仍从 dsh 0.2.1-rc.2 起；`sidebar.panellist` + `main` 在 0.2.0-rc.2 已存在 |

---

## 用户可见变化

- **左侧栏新增「MCP 管理」**。点开是同一个服务器列表页，整页宽度比设置弹窗宽；
  侧栏收起成 56px 轨道时只显示图标，悬停或键盘聚焦显示名称。图标为数据库形状，
  位置紧跟「插件」。
- **两个入口并存一个版本**。新页面顶部写明旧设置页会保留到下一个版本；旧设置页
  顶部写明新入口的位置，并说明本页将在下一个版本移除。
- **隐藏方式不变**。只关闭 manager bundle 所含的 `mcp-project-ui`（或 profile
  patch 按 id 覆盖禁用）就同时隐藏左侧栏与设置页两个入口，装载器继续运行。

---

## 迁移提示

- 升级到 0.10.0 后无需改配置、无需迁移文件；两个入口读写的仍是同一批受管
  `mcp.yml`。
- 0.11.0 会移除设置标签页。如果你的操作手册或内部文档写着
  「设置 → 内置插件 → 插件：MCP 管理」，现在就可以改成左侧栏「MCP 管理」。
