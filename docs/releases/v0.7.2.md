# 发布说明 v0.7.2（查询面推送）

[← 返回 README](../README.zh.md) ｜ 相关：[查询面](../guide/service.zh.md) ·
[v0.7.1 发布说明](v0.7.1.md)

**发布日期**：2026-10-02 ｜ **区间**：`v0.7.1 → v0.7.2`
**宿主**：dsh `0.2.0` 线（从 `0.2.0-rc.2` 起），与 v0.7.1 相同。装载语义不变。

v0.7.2 让配套 UI 不用再定时轮询 `snapshot()`。对账成功结束时发一条进程内事件，
视图类型从包入口具名导出。浏览器 SSE 仍由 UI 包自建。

---

## 亮点速览

| 主题 | 一句话 |
|---|---|
| 变更事件 | 对账成功结束 `ctx.emit("projectMcp/updated")`，无载荷；监听方再读 `snapshot()` |
| 具名类型 | 包入口导出 `ProjectFileState`、`McpServerRuntimeView`、`McpServerView`、`McpRowSource` 等，并开始生成 `.d.ts` |
| 稳定性 | 方法、事件与这些视图类型对配套 UI 按语义化版本承诺；UI 包以同一精确版本 peer-depend |

---

## 变更明细

- **变更事件**：每次成功的 `reconcileAll` 结束（含指纹未变、跳过重读但仍跑完巡检的那一轮）
  emit `projectMcp/updated`。查询方法本身不发。监听方抛错记一条
  `项目 MCP 变更事件投递失败：…`，对账仍算成功。
- **类型出口**：`declaration` 打开后 `lib/index.d.ts` 才存在；`package.json` 的 `types`
  指向它。`exports` 仍不开放 `lib/` 深导入。
- **配套 UI**：查询面从「不承诺稳定」改为对该消费方按语义化版本演进。patch 保持形状，
  minor 只增加，major 才删除或改名。peer 写成精确版本，不要 `^` / `~`。
